# John Henry Supermarkets - compiled demo (reference copy)

This is the BUILT output of a clickable retail-operations demo (role-based dashboards, mock data in /mock).
It is compiled/minified - it is NOT source code. Use it as a visual + data-model reference.

## View it locally
Open a terminal in this folder and run:
    python -m http.server 8080
then open http://localhost:8080  (double-clicking index.html will not work - browsers block module scripts/fetches from file://)

## Use with Claude Code
Treat this folder as read-only reference. Ask Claude Code to study /mock/*.json and write SPEC.md
(roles, screens, data model) before any app code is written.
